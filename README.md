# Movie Explorer (Flutter Web)
Responsive movie browsing app: search, genre filter, favorites, reviews, add-movie form.

Concepts: widgets (Grid/List/Stack/Card), responsive grid + layouts, named-route navigation,
animations (Hero, TweenAnimationBuilder, AnimatedSwitcher), Provider state, custom widgets + theme, validated forms.

Run: `flutter create . --platforms web && flutter pub get && flutter run -d chrome`
Deploy: push to `main`; GitHub Actions publishes to GitHub Pages.
